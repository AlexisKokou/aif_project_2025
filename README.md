## 📌 Project Overview
This project focuses on integrating AI tools into a movie streaming platform for different tasks:

- 🖼️ **Validate a Movie Poster**: Detect whether the uploaded image is a valid poster or not  
- 🎭 **Predict Movie Genres from Posters**: Predict a movie's genre using its poster  
- 📝 **Plot-based Recommendation**: If a poster is invalid or not available, predict the genre using the movie plot and recommend films with similar genres  
- 💬 **Natural Language Movie Discovery**: Chat with the platform in natural language to find movies users might like

## 🚀 How to Run

### **1. Clone the Repository**
First, clone the GitHub repository:

```sh
git clone https://github.com/AlexisKokou/aif_project_2025.git
cd aif_project_2025
```
Then open a terminal in the project directory to run the following commands.
### **2. Build the Project**
Run:
```sh
docker-compose build
```

### **3. Start the Containers**
Run:
```sh
docker-compose up
```
After this command, wait a few minutes until all APIs restart completely.

### **4. Use the Web Platform**
Access the website here:

•	http://localhost:7860
### **5. Stop the Containers**
To stop the application, press Ctrl + C in the terminal where it is running.
To remove the containers, use:
```sh
docker-compose down
```
