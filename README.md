## Project Overview:
This is a project about integrating AI tools into a movie streaming platform for different tasks: 
- **Validate a movie Poster**: Detect whether the uploaded image is a valid poster or not
- **Predict Movie Genres from posters**: Predict a movie's genre by using its poster
- **Plot-based recommendation**: If a poster is invalid or not available, then we predict the genre by the movie plot. Then we recommend some films of the same genres. 
- **Natural language movie discovery**: Chatting with the platform in natural language to find movies the users might like
